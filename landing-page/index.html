Xarab is an open-source terminal coding agent that routes requests to the models you choose. Inspect and edit your project, run commands, and delegate focused work.

01 / Routing ledger

One request.
Three capability tiers.

Xarab's configurable classifier estimates what capability a task calls for, then hands the request and relevant context to the worker assigned to that tier. You decide which models do the work.

01 / FOCUSED

Clear, bounded work

Explain a concept or make a straightforward change using established patterns.

02 / ADVANCED

Investigation & judgment

Trace a bug across modules or implement a feature after understanding existing conventions.

03 / SPECIALIZED

Deep, specialized reasoning

Navigate difficult performance work, security design, or high-consequence trade-offs.

Request → classify → work → response

Choose a classifier and assign a worker to each tier in /route. The classifier considers your request and limited recent context, then the selected worker takes on the task. You can inspect the tier and rationale. A worker can request a checked handoff if the work needs a different capability.

Tiers describe capability—not model size, task length, or file count. Routing is a strategy, not a guarantee of lower cost, faster answers, or better results; metadata labels do not guarantee a model is best suited to a task.

03 / Capability index

What the agent
can do.

Routing is a starting point—not a black box. Tune your setup, inspect the choice, and keep working in the project you already have.

01 / ROUTING

Choose and understand

Configure models independently, see the selected tier and rationale, and evaluate a local classifier against labeled examples.

02 / WORKSPACE

Work in your project

Inspect and edit files, search code, run commands, and use optional web research. Command risk is assessed; some commands need your approval.

03 / DELEGATION

Delegate focused work

Delegate isolated subtasks with built-in or project agent profiles. Subtasks share the workspace, not a sandbox; concurrency is not guaranteed.

04 / SESSIONS

Keep context moving

Restore and compact saved sessions, queue follow-ups while work runs, and review suggested next messages when available.

Connect MCP servers

Add local or remote MCP servers to give Xarab access to additional tools. Workspace server connections require approval, and each MCP tool call requires your approval. Servers are not sandboxed by Xarab's workspace file restrictions.

Choose where models run

Three ways to
power the agent.

Xarab supports the same provider options for classification and worker execution. Choose independently for each role and tier; the lineup can be all-local, hosted, or mixed.

01 / HOSTED · SIGN IN

OpenAI

Connect with ChatGPT sign-in in /connect. Xarab uses its OpenAI Responses integration for classification or worker requests.

Auth: ChatGPT sign-in
02 / HOSTED · API KEY

OpenRouter

Add an OpenRouter API key in /connect, then choose a model in /route. Access the models available through your OpenRouter account.

Auth: OpenRouter API key
03 / LOCAL · GGUF

Run models locally

Use compatible GGUF models on your own machine through node-llama-cpp. Browse downloads with /download and assign models in /route.

Needs compatible hardware

Local inference requires compatible hardware. Separately configured tools and integrations may still use network services; hosted providers may charge for usage.
